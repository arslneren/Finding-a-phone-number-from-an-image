# Ek fontlar

Buraya koyduğunuz `.ttf`, `.otf` ve `.ttc` fontlar sistem fontlarıyla birlikte veri üretiminde kullanılır. Örneğin *Noto Sans Symbols 2* eklenirse sistemde fontu olmayan segment rakamlar (🯰🯱🯲) da veriye girer.

Font ekledikten sonra `data/font_coverage.json` dosyasını silip veriyi yeniden üretin. Fontlar lisans nedeniyle GitHub'a yüklenmez.
